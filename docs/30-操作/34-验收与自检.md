# 验收与自检

## 1. 基线命令

```bash
python -m pytest -q
python main.py --self-test
python init.py --check
python tools/check_repo_hygiene.py
```

预期：

- pytest 全通过；允许因缺少本地源文件而 skip。
- `--self-test` 打印 `self-test 通过`、归档文件与入库题数。
- `init.py --check` 显示环境/覆盖；可选资源缺失只应是 INFO/WARN。
- hygiene 打印 `repo hygiene OK`。

## 2. 离线生成 smoke

```bash
python main.py "生成2道第44课读音题" --dry-run --offline --seed 7
```

预期：`完成：2/2 题；失败 0`，`本地指标` 一行，`dry-run：未写入数据库/Markdown`。

不需要 LLM、UniDic、MDict、原题库。

## 3. 写库 + 审计

```bash
python main.py "生成2道第44课读音题" --offline --seed 7
python main.py --audit
```

预期：

- 第一条写 `data/db/big2_autumn.sqlite3` 与 `data/exams/big2_autumn/`（均 gitignored）。
- `--audit` 输出审计批次、items 数、回环 violations、无 carrier、试题册泄漏、请求 key 泄漏、答案册题号；结论 `OK`。
- 审计失败时 exit 1，明细最多 20 条。

## 4. 迁移 dry-run

```bash
python tools/migrate_items_v1.py --dry-run
```

预期：打印 `[DRY-RUN] scanned=... migrated=... skipped_existing=...`，不写 items/quarantine。旧题不可迁移时列出 `quarantine:E_*` 计数。

## 5. 文档闸门

```bash
python tools/docs.py index --check
python tools/docs.py lint
python tools/docs.py lint --simulate-missing "20-模块/24-装配审计与降级.md"
wc -l CLAUDE.md
```

预期：

- `index --check` 打印 fresh。
- `lint` 打印 `docs lint OK`。
- `--simulate-missing` exit 1，并报出指向该文档的死链/路由缺口；这证明引用图真实有效。
- `CLAUDE.md` ≤120 行。

## 6. 单任务加载预算

以“改语法题干扰项”为例，只读：

```text
CLAUDE.md
docs/10-契约/15-不变量与缺陷码.md
docs/20-模块/24-装配审计与降级.md
```

记录三文件行数；任务文档合计 ≤800 行（CLAUDE.md 固定开销另报）。实际行数写入 [90-归档/2026-11-17-基线快照](../90-归档/2026-11-17-基线快照.md)。

## 7. 红线与引用图

```bash
python tools/docs.py lint --json
```

`--json` 输出 `routes`（任务、必读、行数）、`fail`、`warn`。用于确认：

- 12 条红线各一个 owner；
- 每条路由必读 ≤3 篇；
- 没有死链/未登记 DRIFT；
- `core/*.py` 与根入口都被文档 `代码` 覆盖。

## 8. 提交前清单

1. `python tools/docs.py index`（若文档有改动）。
2. `python tools/docs.py lint`。
3. `python tools/docs.py index --check`。
4. `python -m pytest -q`。
5. `python main.py --self-test`。
6. `python tools/check_repo_hygiene.py`。
7. 代码改动带对应 L1/L2 文档 diff；红线/L0 改动带 ADR。
