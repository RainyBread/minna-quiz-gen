# 排障与降级

## 1. 配置错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `配置错误：... 非本地主机使用明文 http` | `LLM_BASE_URL` 使用了非 localhost/私网的 `http://` | 改 `https://`，或仅本地代理用 `http://localhost`。 |
| `配置错误：... 缺少 Key`/LLM 不可用 | 未设置 Key，或 provider/host 不匹配 | 设置 `LLM_API_KEY`；或按 host 设置 `DEEPSEEK_API_KEY`/`STEPFUN_API_KEY`/`ANTHROPIC_API_KEY`。 |
| `SemesterViolation` | `ACTIVE_SEMESTER` 不是 `big1_spring`/`big2_autumn` | 改 `.env`；大二下/未知学期不支持。 |
| `.env.bak` 含 Key | `simplify_env` 迁移产生 | 不分享、不云同步；确认后删除。 |

配置错误返回 exit 2；不会打印 Key。

## 2. LLM 失败

| 现象 | 处理 |
|---|---|
| `LLMUnavailable: 模拟卷需要 LLM` | 配置 Key，或改用 `--offline` 出读音/汉字。 |
| 401/403 | Key 错误/过期；检查 provider 与 base URL；认证类错误会立即熔断。 |
| 连续超时/连接失败 | 单题重试 2 次；连续 3 次非致命失败熔断；检查网络/代理。 |
| 标签缺失/span 不合法 | 单题拒题，继续其它题；看 `RunFailure` 的 `E_*`。 |
| prompt 中出现 Key | 不应发生；检查 `sanitize_secret_text` 与请求日志。 |

`--dry-run` 仍会调用 LLM；要完全离线用 `--offline`。

## 3. 数据/词典缺失

| 缺失 | 行为 |
|---|---|
| `vocab.json`/`grammar.json` | `ContextError` 硬失败；先准备运行数据。 |
| `question_types.json`/`common_mistakes.json` | 空默认；题型权重回退 blueprint。 |
| `locks.json` | 无线索/锁词增强；可能增加裸框架拒题。 |
| `extension_vocab.json` | 拓展池为空；`extend` 回退课内。 |
| `item_bank.local.json` | 纯新题；来源配比降级并写 warning。 |
| UniDic | 读音题用教材 `kana`；`unidic_verified=false` 条目跳过。 |
| MDict | 拓展/释义增强不可用；`scope` 回退课内。 |
| `mdict-utils` 未安装 | `.mdx` 被发现但查询为空；安装 `requirements-local.txt`。 |

## 4. 审计失败

```bash
python main.py --audit
python main.py --audit <batch_id> --json
```

| 字段 | 含义 | 处理 |
|---|---|---|
| `round_trip_violations` | slot/span/key 不一致 | 检查该 Item 的 carrier/slots；旧题用迁移工具重建。 |
| `missing_carrier` | 无法渲染/缺 carrier | 旧 schema 或空 carrier；迁移/丢弃。 |
| `view_leaks` | 试题册含答案/解析 | 检查 `core.render` 视图；不要用题干拼答案。 |
| `request_key_leaks` | prompt 含未允许的 key/干扰项/解析 | 检查 `prompt_visible` 与 `mask_secrets`；不要提示正确答案。 |
| `answer_mismatch` | 试题册/答案册题号不一致 | 检查 render 输入顺序与题号。 |
| `legacy_skipped` | 旧 schema 无法解析 | 可接受；迁移后应减少。 |

审计不调用 LLM/MDict；失败不会自动修复。

## 5. 迁移 quarantine

```bash
python tools/migrate_items_v1.py --dry-run
python tools/migrate_items_v1.py --apply
```

- `data/exams/quarantine/<batch>-<question>.json`：含 `defect`, `reason`, `before`, `after`。
- 常见 `E_ANCHOR`：旧题干没有唯一 `[[blank]]` 或答案已出现在空格外。
- 常见 `E_ZERO`：旧题干扰项不足/重复。
- quarantine 是本地产物，不提交；修复源数据后重跑。

## 6. 已知漂移（用户版）

| ID | 现象 | 影响 | 处理 |
|---|---|---|---|
| DRIFT-01 | 模拟卷配比键名不一致 | 当前回退到 30/10/5/10/25 | 改 blueprint 后需验证；待修。 |

| DRIFT-07 | 入口顶层导入 miner | 启动加载 miner | 不影响生成执行；待修。 |
| DRIFT-08 | `is_active_target` 未用于守卫 | 禁用学期靠缺数据失败 | 不要依赖它拒绝。 |
| DRIFT-09 | 根 README 仍是旧知识库式文档 | 与 docs 重复 | 以 `CLAUDE.md` + `docs/` 为准；待迁移。 |
