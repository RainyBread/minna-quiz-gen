# 数据制备

## 1. 运行时最小闭包

必读：

```text
data/textbook/big2_autumn/vocab.json
data/textbook/big2_autumn/grammar.json
```

可选并自动降级：

| 数据 | 缺失行为 |
|---|---|
| `question_types.json` / `common_mistakes.json` | 空默认；题型权重回退 blueprint。 |
| `course_profile.json` | 默认来源配比；模拟卷硬编码回退。 |
| `locks.json` | 无线索/锁词增强。 |
| `extension_vocab.json` | 无拓展池。 |
| `existing_question_index.json` | 无真题去重索引。 |
| `item_bank.local.json` | 纯新题。 |
| UniDic/MDict/PDF/raw/drafts | 非运行时必需。 |

契约见 [17-数据分层与隐私](../10-契约/17-数据分层与隐私.md)。

## 2. 数据从哪里来

| 数据 | 来源 | 工具 |
|---|---|---|
| 37-43 词表、2024 真题、blueprint | 旧项目 `dlut-nihongo-quiz/` | `tools/import_legacy.py` / `tools/rebuild_data.py` |
| 44-50 词表/语法 | 教材扫描 PDF | `tools/extract_textbook.py` + 人工审核 |
| 读音复核 | 本地 UniDic | `tools/verify_vocab.py` |
| 语法 answer forms | LLM 候选 + 人工审核 | `tools/fill_grammar_forms.py` + `review_grammar_forms.py` |
| 本地原题库 | `raw_*.json` | `tools/build_item_bank.py` |
| 真题去重索引 | `raw_*.json` | `tools/build_novelty_index.py` |
| 拓展词种子 | 本地 MDict | `tools/build_extension_vocab.py` |
| 规则库 | 词表/真题/blueprint + LLM/人工 | `python init.py --remine` |
| Item 迁移 | 旧归档/DB questions | `tools/migrate_items_v1.py` |

## 3. 常用流程

### 3.1 首次导入旧语料

```bash
python tools/import_legacy.py --force
python init.py --check
```

### 3.2 44-50 教材 OCR（可选）

```bash
python tools/extract_textbook.py --force
python tools/review_textbook.py
python tools/check_drafts.py
python tools/extract_textbook.py --merge
```

OCR 只产出 draft；审核合并后才进入 `vocab.json`/`grammar.json`。需要 `requirements-ocr.txt` 和可选视觉 LLM。

### 3.3 读音复核

```bash
python tools/verify_vocab.py
```

用本地 UniDic 复核 `vocab.json` 读音，回写 `unidic_verified`；没有 UniDic 时跳过。

### 3.4 语法 forms

```bash
python tools/fill_grammar_forms.py --workers 6
python tools/review_grammar_forms.py --merge
```

LLM 只产出候选；人工审核合并。未审核/无批准形式的点不进入运行时候选。

### 3.5 原题库/去重索引

```bash
python tools/build_item_bank.py
python tools/build_novelty_index.py
```

原题库写 `data/exams/item_bank.local.json`（不提交）；去重索引写 `data/exams/existing_question_index.json`（提交）。

### 3.6 拓展词种子

```bash
python tools/build_extension_vocab.py --topics 旅行 食事 --per-topic 20
```

读取本地 MDict；提交 JSON 只放日文词/读音/关系/通用来源类型，不写中文释义。

### 3.7 规则库

```bash
python init.py --remine
```

确定性挖掘 + LLM 增强 + 人工审核；写 `data/rules/question_types.json`、`common_mistakes.json` 与 `_mining_report.json`。

### 3.8 Item 迁移

```bash
python tools/migrate_items_v1.py --dry-run
python tools/migrate_items_v1.py --apply
```

迁移旧归档/DB questions 到 Item v1；失败写 `data/exams/quarantine/`，不重写旧归档。

## 4. 提交与忽略

提交：`data/textbook/big2_autumn/` 的 allowlist JSON、`data/rules/` 两个 JSON、`data/exams/existing_question_index.json`。

不提交：PDF/docx、MDict/UniDic、DB/cache/logs、`raw_*`、`*.local.json`、drafts/OCR、生成批次、`data/exams/items/`、`data/exams/quarantine/`、`.env`。

## 5. 失败与降级

- 源文件缺失：导入工具报缺失；测试 skip；不要伪造数据。
- OCR/视觉依赖缺失：跳过 OCR，使用已有 draft。
- 无 LLM：`mine(offline=True)` 只跑确定性规则。
- 审核拒绝：保留 draft/history，不合并。
- 迁移失败：写 quarantine，继续其它题。

## 6. 验收

```bash
python init.py --check
python tools/check_repo_hygiene.py
```

`init.py --check` 显示词表/语法/规则/锁表/原题库覆盖；hygiene 确认没有版权/密钥资产被跟踪。
