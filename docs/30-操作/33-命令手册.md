# 命令手册

## 1. `main.py`

```text
python main.py [request] [开关]
```

| 参数 | 说明 |
|---|---|
| `request` | 自然语言需求；省略则进入 REPL。 |
| `--mock` | 80 题五类模拟卷；无 request 时自动用“生成一套模拟卷”。 |
| `--scope {in_syllabus,mdict_distractors,extend}` | 课内 / 课内+拓展干扰 / 拓展学习。 |
| `--topic TOPIC` | 拓展主题。 |
| `--use-case {first_learn,unit_test,mock,review}` | 来源配比预设。 |
| `--workers N` | LLM 并发数。 |
| `--seed N` | 随机种子。 |
| `--answers {auto,separate,inline,only,hidden}` | 答案呈现。 |
| `--reveal` | hidden 模式逐题揭示答案。 |
| `--hide-answers` | 流式不打印答案/解析。 |
| `--no-stream` | 全部完成后统一渲染。 |
| `--dry-run` | 不写 DB/Markdown/曝光；仍可能调用 LLM。 |
| `--json` | 输出批次 JSON。 |
| `--offline` | 禁用 LLM，仅本地读音/汉字题。 |
| `--health` | 环境检查。 |
| `--list` | 列出批次。 |
| `--export BATCH_ID` | 导出批次 Markdown。 |
| `--no-answers` | 导出学生版（不含答案）。 |
| `--self-test` | 离线自检（临时目录）。 |
| `--audit [BATCH_ID]` | 审计 Item/视图/请求日志；省略批次审计最近一批。 |

示例：

```bash
python main.py "生成3道第44课读音题"
python main.py "生成2道第44课语法题" --dry-run
python main.py "生成一套模拟卷"
python main.py --mock --answers separate
python main.py "围绕旅行生成10道拓展题" --scope extend --topic 旅行
python main.py --offline "生成3道第44课读音题"
python main.py --audit
python main.py audit --json
```

## 2. `quiz.py`

薄入口：

```bash
python quiz.py audit [BATCH_ID] [--json]
```

`audit` 之外参数转交 `main.py`。退出码与 `main.py --audit` 一致：0 通过，1 审计失败。

## 3. `init.py`

| 参数 | 说明 |
|---|---|
| `--check` | 只做环境/覆盖检查，不写数据。 |
| `--check-dev` | 检查中显示开发语料状态。 |
| `--remine` | 重新挖掘规则并人工审核。 |
| `--offline` | 禁用所有 LLM 调用。 |
| `--yes` | 非交互确认规则审核。 |
| `--skip-mining` / `--no-import` / `--no-ocr` | 已废弃 no-op。 |

```bash
python init.py --check
python init.py
python init.py --remine
```

## 4. REPL

`python main.py` 或 `python init.py` 进入。

```text
/help /list [n] /show <batch_id> /export <batch_id> [--no-answers]
/rules [rule_id|diff] /approve <rule_id> /reject <rule_id> /remine
/stats /env /dict <word> /extend [topic|build topic]
/mode <scope> /seed <int> /workers <int> /quit
```

- `/dict` 查询本地全部 MDict。
- `/extend build <topic>` 构建/合并拓展词。
- `/stats` 输出 JSON：学期、DB、题数、批次、按题型/课次/规则统计。

## 6. 退出码

| 场景 | 码 |
|---|---|
| 正常完成 | 0 |
| 文档 lint/审计失败 | 1 |
| 配置错误（`ConfigurationError`/`SemesterViolation`） | 2 |
| 参数/IO 错误 | 2 |

单题失败不改变退出码；批次仍成功时返回 0，失败题在输出/`RunResult.failures` 中。

## 7. 注意

- `--dry-run` 不是离线；它只阻止写 DB/Markdown/曝光。
- `--offline` 禁用 LLM；模拟卷会报错。
- `--mock` 指 80 题模拟卷，不是 LLM mock。
- `--json` 与 `--no-stream` 可组合；`--json` 优先只输出 JSON。
- 详细降级见 [35-排障与降级](35-排障与降级.md)。
