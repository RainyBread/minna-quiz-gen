# 快速上手

## 1. 环境

- Python 3.11+（当前开发环境 3.13）。
- Windows Git Bash 或等价 shell；项目在仓库根目录直接运行，不需要 `pip install -e .`。
- 运行数据已随仓库提供；UniDic/MDict/原题库可选。

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
```

开发/本地增强：

```bash
pip install -r requirements-dev.txt    # pytest
pip install -r requirements-local.txt   # UniDic(fugashi) + MDict(mdict-utils)
pip install -r requirements-ocr.txt     # 仅 OCR/PDF 构建期
```

## 2. 配置 LLM（可选）

```bash
cp env.template .env
# 只填 LLM_API_KEY；默认 DeepSeek-compatible / deepseek-chat
```

- 读音/汉字题不需要 Key。
- 模拟卷需要 LLM；无 Key 会明确报 `LLMUnavailable`。
- `LLM_PROVIDER=anthropic` 时默认 base URL 为 `https://api.anthropic.com`，Key 用 `ANTHROPIC_API_KEY` 或显式 `LLM_API_KEY`。
- 非本地 `http://` base URL 会被拒绝，避免明文传 Key。

## 3. 检查与启动

```bash
python init.py --check
python init.py
```

`init.py` 默认只做快速检查并进入 REPL；不会导入语料、跑 OCR 或重新挖掘规则。`--check` 只检查，不写数据。

REPL 示例：

```text
jp> 生成一套模拟卷
jp> 生成3道第44课读音题
jp> 生成2道第44课语法题
jp> 围绕旅行生成10道拓展题
jp> 只出课内题
jp> /help
```

## 4. 一次性出题

```bash
python main.py "生成3道第44课读音题"
python main.py "生成2道第44课词汇题" --dry-run
python main.py "生成一套模拟卷"
python main.py --mock
```

常用开关：

- `--offline`：禁用 LLM，仅本地读音/汉字题。
- `--dry-run`：不写 DB/Markdown/曝光（仍可能调用 LLM）。
- `--seed 7`：复现选项顺序。
- `--answers separate|inline|only|hidden`：答案呈现。
- `--no-stream`：全部完成后统一渲染。

## 5. 输出在哪

- 批次 JSON/Markdown：`data/exams/big2_autumn/`（gitignored）。
- SQLite：`data/db/big2_autumn.sqlite3`（gitignored）。
- LLM 请求日志：`data/logs/llm_requests/`（gitignored）。
- 审计：`python main.py --audit`。
- 复现视图：`python tools/render_batch.py --batch <id> --out data/cache/render-check`。

## 6. 离线自检

```bash
python main.py --self-test
```

走通本地读音题 → Item → 归档 → DB → Markdown，不需要 LLM/UniDic。
