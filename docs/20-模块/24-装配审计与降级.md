# 装配审计与降级

## 1. 职责与边界

把 `GeneratedQuestion` 转成 canonical `Item`，做结构校验，跑失败链，汇总批次，并提供只读审计。不做语义判断、不调用 LLM/MDict 审计、不自动修复 Item。

- `core.items`：Item schema、slot/hash、`validate_item`、legacy 投影。
- `core.runner`：扇出、线程池、即时题/LLM 题、降级链、`_build_batch`、指标。
- `core.audit`：读 Items/请求日志，检查回环、视图泄漏、请求泄漏、题号一致。
- `core.similarity`：字符 n-gram 重合度，用于指标。

## 2. 输入输出契约

输入：`QuizPlan`、`QuestionSpec` 列表、`GeneratedQuestion`、`AppContext`、`ItemBank`、`LockTable`、`LLMClient`。

输出：

- `RunResult`：`GeneratedBatch`、`items`、`failures`、`warnings`、`json_path`、`md_path`、`duplicates`。
- `GeneratedBatch.items`：canonical Item JSON 列表。
- `GeneratedBatch.questions`：legacy 投影。
- `BatchMeta.metrics`：来源/域/考点覆盖/重合/超纲/裸框架/同场无线索/答案分布。
- `AuditReport`：见 [L1-15](../10-契约/15-不变量与缺陷码.md)。

## 3. 数据与依赖

- `core.context.AppContext`：词表/语法/规则/课程/新颖度。
- `core.db`：曝光读取、批次写入、Items 写入。
- `core.exporter`：归档 JSON/Markdown。
- `core.render`：控制台逐题渲染与指标答案分布。
- 不依赖 UniDic/MDict 做 Item 校验；这些只在备料/生成段使用。

## 4. 本地不变量

- 每个 Item 的 slot 满足 `carrier[start:end] == span`；填空槽等于 `key.value`。
- key + 3 个唯一干扰项；否则 `E_ZERO`。
- explanation 非空；否则 `E_PARSE`。
- `meta.hashes` 与 canonical Item 一致；否则 `E_PARSE`。
- 批次 `accepted <= expected`；失败题记录在 `RunFailure`，不写空题。
- 指标只读 Item/Question，不修改它们。

## 5. 失败与降级

`_finalize` 是唯一入口：

1. `build_item_from_generated_question`。
2. `validate_item`；有缺陷立即抛 `ItemBuildError`。
3. `project_generated_question` 生成 legacy 视图。
4. 若 Item 无课次而 spec 有，补 `meta.lessons` 并刷新 hash。

降级链：

- 即时题：original → variant → 未曝光 original → new/local。
- LLM 题：重试 2 次 → original → variant → local grammar。
- 连续 3 次非致命失败熔断；认证/连接类错误立即熔断。
- 无可生成题：`QuestionBuildError`，不写空批次。

没有修复算子；`ItemMeta.repairs` 未使用。

## 6. 扩展点

- 新缺陷码：在 `validate_item`/`generate_llm` 增加，同步 L1-15 登记与测试；不要让 `_finalize` 吞掉。
- 新指标：在 `QuizRunner._metrics` 增加只读计算，不据此拒绝题目。
- 新审计项：在 `audit_items` 增加只读检查，报告字段加到 `AuditReport`；不得打印完整答案。
- 新降级步骤：在 `_run_llm`/`_generate_instant` 的固定链中插入，并更新 L1-15。

## 7. 验收

```bash
python -m pytest -q tests/test_generator.py tests/test_validator.py
python main.py --self-test
python main.py --audit
```

`--self-test` 走通 Item 构造/校验/归档/DB；`--audit` 对最近一批检查回环/视图/请求泄漏。
