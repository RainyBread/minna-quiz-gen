# 导出与视图

## 1. 职责与边界

从 canonical Item 派生可读视图并归档。答案只从 `ItemKey.value` 读取，不从题干或选项顺序反推。legacy Markdown 仅用于无 Items 的旧批次。

- `core.render`：`AnswerMode`、`render_item`、stem/key/inline、试题册/答案册。
- `core.exporter`：归档 JSON、试题册/答案册、`items.jsonl`、inline、学生版。
- `tools/render_batch.py`：从 DB Items 复现试题册/答案册/manifest。

## 2. 输入输出契约

输入：`GeneratedBatch`（含 Items）、`Item`、`seed`、`AnswerMode`。

输出：

- `RenderedQuestion`：`number`, `item_id`, `type`, `lesson`, `domain`, `source`, `stem`, `options`, `answer_key`, `key_text`, `reading`, `explanation`, `point`。
- 归档：`<batch>.json`、`<batch>.md`（试题册）、`<batch>-answers.md`、`<batch>.items.jsonl`；inline 模式 `<batch>-inline.md`。
- `render_batch`：`questions.md`、`answers.md`、`manifest.json`（item_ids/item_hashes）。

答案模式：`auto`/`separate`/`inline`/`only`/`hidden`。`auto` 对模拟卷用 separate，对练习用 hidden。

## 3. 数据与依赖

- `batch.items`：canonical Item JSON；优先使用。
- `batch.questions`：legacy 投影；无 Items 时回退。
- `batch.batch_meta.seed`：复现选项顺序。
- `batch.batch_meta.answers_mode`：决定输出形态。
- `data/exams/<semester>/`：归档目录；gitignored。

## 4. 本地不变量

- `render_item` 必须得到 4 个唯一选项；否则 `RenderError`。
- 选项字母由 `random.Random(f"{seed}:{item.id}:options")` 打乱后分配；同 seed/Item 可复现。
- `answer_key` 通过 `item.key.value` 匹配选项文本得到，不读题干。
- 试题册不得包含“答案：/解析：/正确答案”标记；答案册不得依赖题干。
- 归档路径必须留在 `settings.exam_dir` 内；`_safe_output_path` 防目录穿越。

## 5. 失败与降级

- 选项不是 4 个唯一值 → `RenderError`；该 Item 不被渲染。
- 批次无 Items 或渲染为空 → `export_batch_markdown` legacy 回退（DRIFT-03）。
- 归档路径不安全 → `ValueError`；不写文件。
- `render_batch` 无 Items → 打印 `no items`，exit 1。

## 6. 扩展点

- 新视图：在 `core.render` 增加 `*_view`/`*_book`，输入 `RenderedQuestion`，不要从 stem 推导答案。
- 新导出格式：在 `core.exporter` 增加函数，保持 `_safe_output_path` 与 Items 优先。
- 新答案模式：`AnswerMode` + `resolve_answer_mode` + CLI `--answers`；同步测试。
- 新复现工具：复用 `render_item` + manifest hash，不重新生成题目。

## 7. 验收

```bash
python -m pytest -q tests/test_db_exporter.py
python main.py --self-test
python tools/render_batch.py --batch <batch_id> --out data/cache/render-check
```

`test_db_exporter` 覆盖归档、学生版、批次列表；`render_batch` 用 DB Items 复现试题册/答案册与 manifest。

## 8. 已知缺陷

- DRIFT-03：无 Items 的旧批次仍回退 `export_batch_markdown`；新批次应始终带 Items。
- `render_batch_console` 仍存在旧控制台渲染；新入口优先用 `core.render`。
- 答案模式 `only`/`inline` 的 CLI 组合需以 `--help` 与测试为准。
