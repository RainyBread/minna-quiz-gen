# 备料与词典

## 1. 职责与边界

为 `QuestionSpec` 提供候选词/语法点、干扰项与读音/释义增强。不做生成、不写库、不决定配额。

- 候选池：`TextbookPools` 按课次/题型抽样，带历史频次与新颖度惩罚。
- 锁表：`LockTable` 提供语义场、反义对、搭配、线索标记与干扰项选择。
- 读音：`UniDicRetriever` / `MockRetriever`，工厂 `create_retriever`。
- 词典：`MDictIndex` 递归发现 `.mdx`，按内容分类，查询中文释义/读音/关联词。
- 拓展：`ExtensionPool` 读取 `extension_vocab.json`，运行时补 MDict 释义/读音。

## 2. 输入输出契约

输入：`AppContext`、`used_target_counts`、`ItemBank`、`ExtensionPool`、`MDictIndex`、`Settings`。

输出：

- `TextbookPools.sample_vocab` / `sample_grammar` → 词条/语法点 + 形式。
- `LockTable.select_vocab_distractors` → 干扰项文本列表。
- `create_retriever().get_reading` → `ReadingResult`。
- `MDictIndex.chinese_gloss/reading/related_words` → 文本/关联词。
- `ExtensionPool.sample` → `ExtensionItem`。

不变量：目标词/正确项默认课内；只有 `scope=extend` 才允许教材外目标。

## 3. 数据与依赖

- 必读：`data/textbook/big2_autumn/vocab.json`、`grammar.json`。
- 锁表：`data/textbook/big2_autumn/locks.json`（反义对/语义场/搭配/线索标记）。
- 拓展：`data/textbook/big2_autumn/extension_vocab.json`（只存日文词/读音/关系，不存中文释义）。
- 本地可选：`data/unidic-cwj-*/`、`data/mdicts/*.mdx`；均 gitignored。
- Python 可选依赖：`fugashi`（UniDic）、`mdict-utils`（MDict 查询）。

## 4. 本地不变量

- `vocab.json` 中 `unidic_verified=false` 的条目不得进入读音/汉字题；词义题保留。
- 干扰项与正确项不同语义场优先；同场时必须有线索，否则不选。
- `LockTable.is_clue_present` 要求空格外文本 ≥10 字；或空格外 ≥8 字且线索 ≥2 字；或含 `clue_markers`。
- MDict 查询只返回通用类型；仓库可见文件不得出现具体词典名。
- 拓展词中文释义运行时从 MDict 获取，不写进提交 JSON。

## 5. 失败与降级

| 缺失 | 行为 |
|---|---|
| UniDic | `create_retriever` 回退 `MockRetriever`；读音题用教材 `kana`。 |
| MDict | `scope` 回退 `in_syllabus`；拓展池为空时回退课内。 |
| `mdict-utils` 未安装 | 发现 `.mdx` 仍显示“可用”，但查询可能返回空；核心读音/汉字不受影响。 |
| `locks.json` | `LockTable({})`；无线索增强。 |
| `extension_vocab.json` | 无拓展池；提示拓展词不足。 |

单题失败由 runner 降级链处理；备料层不吞掉结构性错误。

## 6. 扩展点

- 新检索器：实现 `create_retriever` 的返回接口（`get_reading`/`get_reading_in_context`/`is_known_word`），保持工厂回退。
- 新词典：在 `MDictIndex` 增加查询方法；不要在调用方直接跑 `mdict_utils`。
- 新拓展来源：`ExtensionPool.merge_entries` / `live_extension_candidates`；提交 JSON 只放通用字段。
- 新锁表字段：`locks.json` 增加 `fields`/`antonyms`/`collocations`，并在 `LockTable` 读取。
