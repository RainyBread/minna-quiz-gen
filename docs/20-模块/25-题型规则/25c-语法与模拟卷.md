# 语法与模拟卷

## 1. 职责与边界

生成 `grammar_fill`，并决定模拟卷的题型配比。语法题的正确形式来自已审核语法点；模拟卷只取五类可生成题型。

## 2. 输入输出契约

输入：`QuestionSpec(point, correct_text, approved_forms, example, textbook_lesson)`。

输出：`GeneratedQuestion`，其 Item 的 carrier 含目标语法形式的 slot；`key.value` 是固定形式。

模拟卷：

- `QuizPlan.mode=mock`，`count=80`。
- `type_plan`：读音 30 / 汉字 10 / 词汇 5 / 表达 10 / 语法 25。
- 强制 `scope=in_syllabus`；不含阅读/排序/完形。

## 3. 数据与依赖

- `grammar.json`：`approved_answer_forms`、`form_tags`、`examples`、`lesson`、`status/reviewed`。
- `question_types.json`：题型 `supported`、`weight`、`correct_design`、`allowed_mistake_rules`。
- `course_profile.json`：`blueprints.mock_supported`、`source_mix_presets`。
- `locks.json`：语法干扰项的可接合性检查。
- LLM：语法题的载体句生成；本地语法兜底不需要 LLM。

## 4. 本地不变量

- 运行时只使用 `GrammarFile.approved_points()`；未审核/无批准形式的点不进入候选。
- 正确答案必须原样出现在题干 slot；`approved_answer_forms` 之外的 span 拒题。
- 模拟卷五类计数之和 = 80；自定义题量按比例缩放。
- 记录型题型不得出现在 `GENERATION_TYPES`。
- 语法题干扰项必须同形式/同接续可接合；否则本地补位或拒题。

## 5. 失败与降级

- 无批准形式/例句 → 该点不可用，抽样跳过。
- LLM 失败 → `generate_local_grammar` 用例句兜底；仍失败则拒题。
- 模拟卷无 LLM → `LLMUnavailable`，明确提示配置 Key 或改用离线读音/汉字。
- 配比数据缺失 → 硬编码 30/10/5/10/25 回退（DRIFT-01）。

## 6. 扩展点

- 新语法点：补 `grammar.json` 的 `approved_answer_forms`/`examples`，再跑审核；不要只加 `pattern`。
- 新模拟卷配比：改 `course_profile.json` 的 `blueprints.mock_supported`；当前代码读取路径有漂移（DRIFT-01），改完需验证。
- 新语法干扰规则：`rule_defs` + `question_types.json` + 测试。

## 7. 验收

```bash
python -m pytest -q tests/test_intent.py
python main.py "生成一套模拟卷" --dry-run
python init.py --check
```

`test_mock_exam_counts` 断言 80 题且语法 25；`init.py --check` 显示语法点/forms 覆盖。

## 8. 已知缺陷

- DRIFT-01：`_mock_plan` 读 `mock_blueprint`，数据在 `blueprints.mock_supported`；当前硬编码回退结果相同。
- DRIFT-02：`init.py --check` 报 72/72 forms，运行时只用 `approved_points`；72 是“有非空 forms 的点”，不是全部可用。
- DRIFT-06：`_allowed_options` 遍历全部 72 个语法点，超纲率指标偏宽。
