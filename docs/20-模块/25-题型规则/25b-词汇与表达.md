# 词汇与表达

## 1. 职责与边界

生成 `vocab_choice`（词汇选择）与 `expression_choice`（表达选择）。LLM 只写含固定项的载体句；选项、答案、解析本地构造。

## 2. 输入输出契约

输入：`QuestionSpec`：

- 词汇：`written`、`reading`、`meaning`、`textbook_lesson`、`scope/topic`。
- 表达：`pattern`、`correct_text`、`approved_forms`、`example`。

输出：`GeneratedQuestion`，其 Item 的 carrier 含一个目标 slot；`key.value` 是固定词/表达。

表达题的正确答案来自语法点 `approved_answer_forms`；词汇题来自教材词条。

## 3. 数据与依赖

- `vocab.json`：目标词、读音、中文、课次。
- `grammar.json`：`approved_answer_forms`、例句、课次。
- `locks.json`：语义场、反义对、搭配、线索标记。
- 可选 `MDictIndex`：拓展词/干扰项中文释义。
- `LLMClient`：文本生成；缺 Key 时本题型不可用。

## 4. 本地不变量

- 目标默认课内；`scope=extend` 才允许教材外目标。
- 表达题的正确形式必须在批准形式集合中。
- 题干必须有决定性线索；否则 `E_MULTI`。
- 干扰项与正确项不同语义场/同词性优先；去重后 3 个。
- LLM 不写选项/答案字母/解析；出现也不进入活跃路径。

## 5. 失败与降级

- 未配置 LLM → 非模拟卷裁剪为读音/汉字；模拟卷报 `LLMUnavailable`。
- span 不是批准形式 → `E_ZERO`；缺完整句 → `E_PARSE`；缺线索 → `E_MULTI`。
- 干扰项不足 → 本地补位；仍不足 → 拒题。
- 单题失败 → runner 降级链（original→variant→local grammar）。

## 6. 扩展点

- 新词汇干扰规则：`rule_defs` + `question_types.json`。
- 新表达形式：`grammar.json` 的 `approved_answer_forms`；先审核再合并。
- 新提示词分支：`build_carrier_prompt`；同步 L1-13 与测试。
- 新拓展来源：`ExtensionPool`；提交数据只放通用字段。

## 7. 验收

```bash
python -m pytest -q tests/test_llm_generation.py
python main.py "生成2道第44课词汇题" --dry-run
```

`test_llm_question_uses_full_sentence_and_pins_correct` 验证 `[s]/[t]` 正确项钉死与本地选项；FakeLLM 不需要真实 Key。

## 8. 已知缺陷

- DRIFT-04：多个 `[t]` 只取第一个；`E_MULTI` 是缺线索。
- DRIFT-05：旧 `build_question_prompt` 未使用，避免误接。
- 表达题依赖已审核语法点；未审核/无批准形式的点不应出题。
