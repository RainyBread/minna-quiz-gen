# 读音与汉字

## 1. 职责与边界

生成 `kanji_to_kana`（看汉字选假名）与 `kana_to_kanji`（看假名选汉字）。纯本地，不调用 LLM；UniDic 不是运行时必需。

## 2. 输入输出契约

输入：`QuestionSpec(qtype, entry, correct_text, textbook_lesson)`。

输出：`GeneratedQuestion`：

- `stem` 是提示句/词形 + `[[blank]]`；正确项是 `entry.kana` 或 `entry.written`。
- 4 个选项：正确项 + 3 个本地构造的干扰项。
- `answer_key` 由渲染阶段分配；Item 本身只存 key。

## 3. 数据与依赖

- `vocab.json`：`written`, `kana`, `unidic_verified`, `lesson`。
- `TextbookPools.sample_vocab`：按课次分桶、历史频次惩罚。
- 锁表/语法数据不参与读音/汉字生成。
- 不需要 `.env`、LLM、UniDic、MDict、原题库。

## 4. 本地不变量

- 正确项来自教材 `kana`（读音）或 `written`（汉字），不由 LLM 生成。
- `unidic_verified=false` 的条目不得进入读音/汉字题。
- 干扰项与正确项同词性/同书写风格优先；去重后必须 3 个。
- 正确答案必须原样出现在题干的 `[[blank]]` 位置。

## 5. 失败与降级

- 无 `vocab.json` → `ContextError`，硬失败。
- 某课无合格词条 → 该题失败，记录 `RunFailure`；不生成空题。
- 干扰项不足 → 本地补位；仍不足则拒题。
- 无 LLM 不影响本题型；`--offline` 可正常出题。

## 6. 扩展点

- 新读音规则：在 `generate_local` 的本地分支增加变换，必须保持“正确项原样锚定”。
- 新干扰项规则：在 `rule_defs` 增加稳定 ID，并同步 `question_types.json` 的 `allowed_mistake_rules`。
- 新词表字段：更新 `models.VocabEntry` 与 `vocab.json`，同步 L1-12。


`test_local_reading_and_kanji_without_unidic` 断言 2 题、每题 4 选项、恰一个 correct 且 `answer_key` 匹配。

## 8. 已知缺陷

- 无本模块特有的已知缺口（核实日期 2026-11-17）；语法点/指标口径的全局漂移见 DRIFT-02、DRIFT-06。
- 读音题依赖教材预复核 `kana`；UniDic 只用于构建期复核，不保证运行时可用。
