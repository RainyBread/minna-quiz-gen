# 题库与曝光记账

## 1. 职责与边界

提供原题库、SQLite 持久化、曝光记账、真题去重索引与旧题迁移。不做生成/选题/渲染。

- `core.item_bank.ItemBank`：本地原题库（`item_bank.local.json`，gitignored）。
- `core.db`：`batches/questions/options/items/exposures` 等表；schema v3。
- `core.novelty.NoveltyIndex`：真题内容哈希/目标词频去重索引。
- `core.fingerprint`：题目指纹/内容哈希。
- `tools/migrate_items_v1.py`：旧 `GeneratedQuestion` → Item v1。

## 2. 输入输出契约

输入：`GeneratedBatch`（含 `items`/`questions`）、`Settings`、旧归档 JSON/SQLite questions。

输出：

- `insert_batch` 返回 `batch_id`, `inserted`, `items_inserted`, `duplicates`, `db_path`。
- `list_items(settings, batch_id)` → canonical Item JSON 列表。
- `latest_batch_id` → 最近批次。
- 曝光：`exposed_points`、`record_exposures`、`used_target_counts`。
- 迁移：`data/exams/items/<batch>.items.json` + `items` 表；失败写 `data/exams/quarantine/`。

## 3. 数据与依赖

- `data/exams/item_bank.local.json`：原题库；不提交。
- `data/exams/existing_question_index.json`：真题去重索引；提交。
- `data/db/big2_autumn.sqlite3`：运行时 SQLite；gitignored。
- `data/exams/quarantine/`、`data/exams/items/`：迁移本地产物；gitignored。
- `GeneratedBatch.items` 是 canonical Item 列表；`questions` 是 legacy 投影。

## 4. 本地不变量

- `items.item_hash` 唯一；同 Item 重复写入被忽略。
- `questions` 的 `UNIQUE(semester, fingerprint)` 防重复入库。
- `exposures` 的 `UNIQUE(user_id, stem_hash)` 防同题重复曝光。
- 已曝光考点不得再用原题；第二次出现必须变体/新题。
- 迁移 Item 的 `provenance.carrier_source=reconstructed` 且 `carrier_verified=false`；不假装是原始 carrier。
- `--dry-run` 不写 DB/不动曝光。

## 5. 失败与降级

- 原题库缺失 → `ItemBank([])`；纯新题。
- SQLite 不可写 → `DatabaseError`；批次生成失败。
- 重复题目 → 跳过并记 `duplicates`；不写空行。
- 迁移失败 → 写 quarantine JSON（缺陷码 + before/after），继续其它题。
- `validations`/`audits` 表是旧流程残留；当前管线不写入。

## 6. 扩展点

- 新表/列：在 `core.db.init_db` 用 `CREATE TABLE IF NOT EXISTS` / `_ensure_column`；同步 schema_version。
- 新去重规则：`core.fingerprint`/`core.novelty`；保持哈希稳定。
- 新迁移目标：`tools/migrate_items_v1.py`；写 items/quarantine，不重写旧归档。
- 新曝光维度：`exposures` 表加列；同步 `record_exposures`/`exposed_points`。

## 7. 验收

```bash
python -m pytest -q tests/test_db_exporter.py
python tools/migrate_items_v1.py --dry-run
python main.py --list
```

`test_db_exporter` 覆盖归档、批次去重、列表/统计、学生版导出；迁移 dry-run 只报告，不写文件。

## 8. 已知缺陷

- DRIFT-03：旧批次可能没有 Items；exporter 回退 legacy Markdown。
- `validations`/`audits` 表与 `existing_fingerprints` 是未使用/遗留接口；不要据此判断当前质量。
- 迁移工具会把无法重建的题写 quarantine；quarantine 是本地产物，不提交。
