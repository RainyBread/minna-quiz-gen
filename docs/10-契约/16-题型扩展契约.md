# 题型扩展契约

<a id="redline-10"></a>
## 红线 10：新增题型按清单一次改全，禁止只改一处

## 1. 题型矩阵

| 题型 | 中文 | 状态 | 生成方式 |
|---|---|---|---|
| `kanji_to_kana` | 日文汉字选假名 | 可生成 | 本地，无 LLM |
| `kana_to_kanji` | 假名选日文汉字 | 可生成 | 本地，无 LLM |
| `vocab_choice` | 词汇选择 | 可生成 | LLM 载体句 + 本地选项 |
| `expression_choice` | 表达选择 | 可生成 | LLM 载体句 + 本地选项 |
| `grammar_fill` | 语法填空 | 可生成 | LLM 载体句 + 本地选项 |
| `translation_choice` | 释义选择 | 记录型 | 不生成 |
| `sentence_ordering` | 句子排序 | 记录型 | 不生成；意图层拒绝 |
| `cloze` | 完形填空 | 记录型 | 不生成；意图层拒绝 |
| `reading` | 阅读理解 | 记录型 | 不生成；意图层拒绝 |

`RECORD_ONLY_TYPES` 只参与配比/记录，不得宣称可生成。

## 2. 没有插件注册表

当前没有 `register_plugin`、entry point、处理器映射或 `@plugin` 装饰器。题型由枚举 + JSON 规则 + 多处分发硬编码。新增可生成题型必须同步修改：

1. `core/models.py` 的 `QuestionType` 枚举。
2. `core/models.py` 的 `GENERATION_TYPES`。
3. `core/models.py` 的 `TYPE_LABELS_ZH`。
4. `core/quizgen.py` 的生成分支（`generate_local` 或 `generate_llm`）。
5. `core/prompts.py` 的提示词分支（若需要 LLM）。
6. `data/rules/question_types.json` 的 `types` 条目（`supported`、`option_count`、`correct_design`、`allowed_mistake_rules`、`prompt_hint`）。
7. 测试：`tests/test_intent.py`、`tests/test_generator.py`/`test_llm_generation.py`、必要时 `test_miner.py`。

只改枚举或只改 JSON 都会导致意图解析、生成、导出、指标中的某一环失效。

## 3. 正确设计

`QuestionTypeRule.correct_design` 必须写清：

- `strategy`：如何确定正确答案。
- `answer_source`：教材 `unidic.kana` / `textbook.vocab.written` / 语法 `approved_answer_forms` / 原题库。
- `verification`：本地可执行的核对方式。

`allowed_mistake_rules` 只能引用 `core/rule_defs.RULE_DEFINITIONS` 中的稳定 ID；设误规则不是修复码。

## 4. 记录型与模拟卷

- 记录型题型可出现在蓝图/配比中，但不进入 `GENERATION_TYPES`。
- 模拟卷默认只取五类可生成题型；`mock_supported` 计数为 30/10/5/10/25。
- 意图层遇到阅读/排序/完形会明确拒绝或降级，不静默生成。

## 5. 词典/导出器扩展

没有“core 零改动”的插件承诺。扩展边界是：

- 检索器：`core.retriever.create_retriever` 返回可用实现；缺 UniDic 时回退 `MockRetriever`。
- MDict：`core.mdict_index.MDictIndex` 封装发现/分类/查询；调用方不直接跑 `mdict_utils`。
- 导出器：`core.exporter` 的函数接收 `GeneratedBatch`/`Item`，不得从题干反推答案。
- 新增词典/导出器可以新增模块，但必须保持上述适配器边界，不把分支散落到 `core` 各处。

## 6. 验收

```bash
python -m pytest -q tests/test_intent.py tests/test_miner.py
python init.py --check
```

新增题型时至少补一条意图解析测试和一条生成测试；`init.py --check` 的规则版本/题型覆盖应更新。
