# 任务单与配比

<a id="redline-8"></a>
## 红线 8：来源槽位扇出前确定，失败只换来源不改配额

## 1. QuizPlan（任务单）

`core.intent.QuizPlan` 是一次请求的可执行计划：

| 字段 | 含义 |
|---|---|
| `raw` | 原始自然语言。 |
| `mode` | `practice` / `mock`。 |
| `scope` | `in_syllabus` / `mdict_distractors` / `extend`。 |
| `topic` | 拓展主题。 |
| `count` | 总题量；`total` 为 `type_plan` 求和。 |
| `lessons` | 教材绝对课次；课程课次 = 教材 - 36。 |
| `type_plan` | 题型 → 题量。 |
| `seed` | 随机种子。 |
| `source` | `local` / `llm` / `default`（解析来源）。 |
| `use_case` | `first_learn` / `unit_test` / `mock` / `review`。 |
| `source_mix` | 原题/变体/新题比例，扇出前确定。 |
| `explicit_*` | 用户是否显式指定题量/课次/题型。 |
| `warnings` | 解析警告。 |

## 2. QuestionSpec（题单）

`core.quizgen.QuestionSpec` 是单题备料结果：

| 字段 | 含义 |
|---|---|
| `seq` | 题号/输出顺序。 |
| `qtype` | 题型。 |
| `scope` / `topic` | 范围/主题。 |
| `source_kind` | `vocab` / `grammar` / `original` / `variant` / `new`。 |
| `written` / `reading` / `meaning` | 目标词/读音/中文。 |
| `pattern` / `correct_text` / `approved_forms` | 语法点/固定形式/批准形式。 |
| `textbook_lesson` / `course_lesson` | 教材/课程课次。 |
| `entry` / `point` / `extension` | 候选来源对象。 |
| `original_item` | 原题库条目。 |
| `point_key` | 曝光/去重键。 |
| `clue` / `clue_hint` | LLM 线索 / 本地线索提示。 |
| `reference_stems` / `anchor_example` | 去重与难度锚。 |

## 3. 来源配比

`data/textbook/big2_autumn/course_profile.json` 的 `source_mix_presets`：

| 用途 | 原题 `original` | 变体 `variant` | 新题 `new` |
|---|---:|---:|---:|
| `first_learn` | 0.50 | 0.30 | 0.20 |
| `unit_test` | 0.20 | 0.30 | 0.50 |
| `mock` | 0.05 | 0.20 | 0.75 |
| `review` | 0.00 | 0.40 | 0.60 |

`_source_slots(total, mix)` 用最大余数法分配整数槽位；`build_specs` 按槽位给每题定 `source_kind`。模型不参与分配。

缺 `item_bank.local.json` 时：

- 原题/变体槽位降级为 `new`。
- 写 warning；不中断。
- 来源配比指标会显示实际值。

## 4. 模拟卷配比

`mock` 默认 80 题五类：

| 题型 | 数量 |
|---|---:|
| `kanji_to_kana` | 30 |
| `kana_to_kanji` | 10 |
| `vocab_choice` | 5 |
| `expression_choice` | 10 |
| `grammar_fill` | 25 |

模拟卷强制 `scope=in_syllabus`；不含阅读/排序/完形。自定义题量按比例缩放并保持整数。

注意：`core.intent._mock_plan` 当前读取 `course["mock_blueprint"]`，而数据键是 `course["blueprints"]["mock_supported"]`，实际走硬编码回退（DRIFT-01）。当前结果相同，但改 blueprint 时不会自动生效。

## 5. 曝光规则

- 已曝光考点（`exposures` 表 / `exposed_points`）不得再用原题。
- 第二次出现必须走变体或新题；变体对已曝光考点要求换题面。
- `used_target_counts` 用于候选池的历史频次惩罚。
- `--dry-run` 不写 DB/曝光，因此不会影响下一次生成。

## 6. 失败与降级

- 单题生成失败：记录 `RunFailure`，继续。
- 原题失败 → 变体 → 新题；LLM 题失败 → 原题/变体/本地语法。
- 配额不因单题失败重抽；实际接受数记入 `BatchMeta.accepted`。
- 失败链详见 [15-不变量与缺陷码](15-不变量与缺陷码.md)。

## 8. 已知缺陷

- DRIFT-01：`_mock_plan` 键名漂移；当前硬编码回退与数据一致，但未来改 blueprint 可能静默失效。
- `source_mix` 不足 1 或含未知键时按比例归一；文档不承诺非法输入的行为。
