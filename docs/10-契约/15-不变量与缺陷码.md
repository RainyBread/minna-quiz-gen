# 不变量与缺陷码

<a id="redline-6"></a>
## 红线 6：只做结构校验与本地清洗，无 LLM judge

## 红线 9：唯一性与可接合性由构造保证

## 1. Item 不变量

| 不变量 | 检查 | 违反码 |
|---|---|---|
| carrier 非空 | `validate_item` | `E_PARSE` |
| 至少一个 slot | `validate_item` | `E_PARSE` |
| slot 偏移在 carrier 内 | `validate_item` | `E_ANCHOR` |
| `carrier[start:end] == span` | `validate_item` | `E_ANCHOR` |
| 填空槽 `span == key.value` | `validate_item` | `E_ANCHOR` |
| key 非空 | `validate_item` | `E_ZERO` |
| 干扰项非空/不重复 | `validate_item` | `E_ZERO` |
| 唯一干扰项 ≥3 | `validate_item` | `E_ZERO` |
| explanation 非空 | `validate_item` | `E_PARSE` |
| `meta.hashes` 与内容一致 | `validate_item` | `E_PARSE` |

生成期还检查：

- 题干必须有一个正确项锚点（`[[blank]]`/`[t]`）；否则拒题。
- 线索存在性：空格外文本 ≥10 字；或空格外 ≥8 字且线索 ≥2 字；或含锁表 `clue_markers`；否则 `E_MULTI`。
- 词性/活用形可接合：`style_key`、`_vocab_stem_conflicts`、`pos_group`。

## 2. 结构缺陷码

| 缺陷码 | 触发条件 | 产生位置 | 当前处理 |
|---|---|---|---|
| `E_PARSE` | carrier/slots/explanation 为空；hash 不匹配；缺完整句 | `items.validate_item` / `quizgen` | `_finalize` 抛 `ItemBuildError`，整题失败 |
| `E_ANCHOR` | slot 越界；`carrier[start:end] != span`；填空槽 `span != key.value`；答案已出现在空格外 | `items.carrier_from_blanked_stem` / `validate_item` | 整题失败，降级链补位 |
| `E_ZERO` | key 为空；干扰项为空/重复；唯一干扰项 <3；span 不是批准形式 | `items.build_item_from_generated_question` / `validate_item` / `quizgen._validate_llm_span` | 整题失败，降级链补位 |
| `E_MULTI` | 题干缺少决定性线索 | `quizgen.generate_llm` | 整题失败，降级链补位 |

说明：

- `E_PARSE/E_ANCHOR/E_ZERO` 是 Item 级结构码；`E_MULTI` 是生成期拒题码。
- `_validate_llm_span` 只抛 `E_PARSE/E_ZERO`；多个 `[t]` 当前只取第一个（DRIFT-04）。
- 没有修复算子；`ItemMeta.repairs` 是保留字段，当前无写入。

## 3. 审计码

`core.audit.audit_items` 只读检查：

| 字段/码 | 含义 |
|---|---|
| `round_trip_violations` | Item 回环恒等失败（slot/span/key 不一致）。 |
| `missing_carrier` | 无法渲染或 carrier 缺失。 |
| `view_leaks` | 试题册泄漏答案/解析；`VIEW_LEAK` 明细。 |
| `request_key_leaks` | prompt 中出现未允许的 key/干扰项/解析；`REQUEST_LEAK` 明细。 |
| `answer_mismatch` | 试题册与答案册题号不一致。 |
| `reconstructed_carrier` | 迁移时重建 carrier 的条目数（不判失败）。 |
| `legacy_skipped` | 旧 schema 无法解析、被跳过的条目数（不判失败）。 |

审计入口：

```bash
python main.py --audit [BATCH_ID]
python quiz.py audit [BATCH_ID]
```

默认审计最近一批；`ok = 无回环失败、无缺 carrier、无视图泄漏、无请求泄漏、无题号不一致`。

## 4. 失败与降级链

1. 原题失败 → 变体。
2. 变体失败 → 未曝光则原题，否则新题。
3. 新题需要 LLM → 线程池；单题失败记录后继续。
4. LLM 连续 3 次非致命失败 → 熔断；认证/连接类错误立即熔断。
5. LLM 题失败 → 原题/变体/本地语法（`generate_local_grammar`）。
6. 所有题失败 → `QuestionBuildError`；不会写空批次。

`--dry-run` 不写 DB/Markdown/曝光；`--self-test` 用临时目录走通归档/DB/Markdown。

## 5. 三层 quarantine

| 层 | 位置 | 含义 |
|---|---|---|
| 导入期 | `QualityStatus.QUARANTINED` | 2024 真题/旧语料导入时质量不合格，保留 `status=quarantined`。 |
| Item 级 | 无静态夹具 | 结构缺陷直接拒题；不写 quarantine 文件。 |
| 迁移期 | `data/exams/quarantine/*.json` | `tools/migrate_items_v1.py` 无法迁移的旧题，含缺陷码与 before/after。 |

迁移 quarantine 是本地生成物，不提交；`.gitignore` 已排除 `data/exams/quarantine/`。
