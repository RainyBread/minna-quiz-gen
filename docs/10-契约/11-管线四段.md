## 1. 运行时四段

| 段 | 入口 | 输入 | 输出 |
|---|---|---|---|
| 解析 | `core.intent.parse_plan` | 自然语言 + `AppContext` | `QuizPlan`（题量/课次/题型/范围/用途/来源配比） |
| 备料 | `core.runner.QuizRunner.run` / `build_specs` | `QuizPlan`、候选池、锁表、原题库、拓展池 | `QuestionSpec` 列表；来源槽位已分配 |
| 生成 | `runner._generate_instant` / `_run_llm` | `QuestionSpec` | `GeneratedQuestion` + canonical `Item` |
| 装配 | `runner._finalize` / `_build_batch` / `exporter` / `db` | 全部 Item | `GeneratedBatch`、JSON/Markdown、DB、曝光记录 |

“装配”包含三件事：Item 结构校验、批次元数据/指标、归档与曝光。正确答案在生成段已由本地钉死，装配段不重新判断语义。

## 2. 构建期与运行时

构建期（默认启动与生成不执行）：

- `core.importer`：旧题库/2024 真题/教材词表/语法/blueprint 导入。
- `core.pdf_importer`：教材扫描 PDF 的 OCR/视觉抽取，只产出 draft。
- `core.miner`：确定性挖掘 + LLM 增强 + 人工审核合并规则。
- `tools/*`：数据制备、复核、迁移、渲染。

运行时（`core.context.load_context`）：

- 必读：`vocab.json`、`grammar.json`。
- 可选：`question_types.json`、`common_mistakes.json`、`course_profile.json`、`locks.json`、`extension_vocab.json`、`existing_question_index.json`、`item_bank.local.json`、SQLite。
- 不在运行时导入语料、不跑 OCR、不重新挖掘。

注意：`main.py` 顶层仍导入 `core.miner`（DRIFT-07）；当前约束是“默认不执行”，不是“导入级隔离”。新增功能不得把导入/OCR 拉进生成链。

## 3. 并行与流式

- 即时题（原题/变体/本地读音/汉字）先执行并逐题打印。
- LLM 题提交线程池；每完成一题立即打印。
- 线程池只跑 LLM 题；`workers` 默认取 `Settings.llm_concurrency`。
- 单题失败记录后继续；连续 3 次非致命失败触发熔断；认证/连接类错误立即熔断。
- `--no-stream` 全部完成后统一渲染；`--json` 只输出批次 JSON。

## 4. 本地构造边界

- 正确项：教材 `kana/written`、语法 `approved_answer_forms`、原题库 `answer_text`。
- 干扰项：锁表/词表/语法池本地构造；LLM 不写选项。
- 解析：本地模板拼“线索 + 正确项释义 + 干扰项释义”；不做排除式论证。
- 来源配比：`source_mix_presets` 在扇出前确定；模型不分配。
- 答案字母：由 `core.render.render_item` 按 seed 打乱后分配；Item 本身没有字母。

## 5. 失败与降级

- 原题失败 → 变体 → 新题。
- 新题需要 LLM 但未配置 → 自动裁剪为读音/汉字；模拟卷直接报 `LLMUnavailable`。
- 原题库缺失 → 纯新题，来源配比降级并写 warning。
- 规则库缺失 → 空默认；题型权重回退 `BLUEPRINT_2024`。
- `vocab.json`/`grammar.json` 缺失 → `ContextError`，硬失败。
- 详细缺陷码与失败链见 [15-不变量与缺陷码](15-不变量与缺陷码.md)。

## 6. 扩展点

- 新题型：按 [16-题型扩展契约](16-题型扩展契约.md) 的清单改；不要只加一个分支。
- 新词典/检索器：实现 `core.retriever` 的检索接口或 `core.mdict_index` 的查询边界，保持 `create_retriever` 工厂可回退。
- 新导出器：在 `core.exporter` 增加函数，输入仍是 `GeneratedBatch`/`Item`，不要从题干反推答案。
