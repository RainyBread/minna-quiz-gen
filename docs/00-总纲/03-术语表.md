# 术语表

> 一条术语只在这里定义；L1/L2/L3 只引用，不另起同义词。代码标识符与中文术语必须一一对应。

## 1. Item 与视图

| 术语 | 代码 | 定义 |
|---|---|---|
| Item | `core.items.Item` | 题目的唯一事实源：carrier + slots + key + distractors + explanation + meta。 |
| 载体句 | `Item.carrier` | 去掉标签后的完整日语句子/对话；正确答案在句中占据一个 slot。 |
| 槽 | `ItemSlot` | carrier 中的一段区间，满足 `carrier[start:end] == span`。 |
| 正确项 | `ItemKey.value` | 本地钉死的答案文本；不是选项字母。 |
| 干扰项 | `ItemDistractor.value` | 本地构造的错误选项；`origin` 记录教材/原题/拓展来源。 |
| 视图 | `core.render` | 从 Item 派生的试题册/答案册/inline 文本；选项字母由 seed 打乱。 |
| legacy 投影 | `GeneratedQuestion` | 旧消费者兼容结构；由 Item 投影而来，不是新逻辑的事实源。 |

## 2. 域与来源（不得混用）

| 术语 | 代码 | 定义 |
|---|---|---|
| 域 | `ItemMeta.domain` | 课内/拓展：`in` / `out`。 |
| 来源 | `ItemMeta.source` | 题目来源：`original` / `variant` / `ai`。 |
| 来源类型 | `QuestionSpec.source_kind` | 生成前的候选来源：`vocab` / `grammar` / `original` / `variant` / `new`。 |
| 范围 | `QuizPlan.scope` | 课内/课内+拓展干扰/拓展学习：`in_syllabus` / `mdict_distractors` / `extend`。 |
| 来源配比 | `source_mix` | 原题/变体/新题的比例；扇出前确定。 |

**域 ≠ 来源**：`domain` 回答“课内还是拓展”，`source` 回答“原题、变体还是新造”。不要把 `mdict_distractors` 当成来源，也不要把它当成域。

## 3. 计划与生成

| 术语 | 代码 | 定义 |
|---|---|---|
| 任务单 | `core.intent.QuizPlan` | 一次请求的可执行计划：题量、课次、题型、范围、用途、来源配比。 |
| 题单 | `core.quizgen.QuestionSpec` | 单题的备料结果：目标词/语法点、正确形式、课次、来源槽位、线索提示。 |
| 考点 | `point_key` | 去重/曝光用的稳定键：词形或语法点 `gp_id`。 |
| 原题 | `source_kind=original` | 来自本地原题库的题。 |
| 本地变体 | `source_kind=variant` | 基于原题/语法点本地改写的题。 |
| 新题 | `source_kind=new` | 由本地构造 + LLM 载体句生成的题。 |
| 记录型 | `RECORD_ONLY_TYPES` | 只记录配比、不生成的题型：释义、排序、完形、阅读。 |

## 4. 唯一性与生成质量

| 术语 | 代码/数据 | 定义 |
|---|---|---|
| 唯一性锁表 | `core.locks.LockTable` / `locks.json` | 语义场、反义对、搭配、线索标记的本地表。 |
| 裸框架 | bare framework | 没有决定性线索、只留空格的题干；直接拒题。 |
| 同场无线索 | same-field-no-clue | 四个选项同语义场且无线索的聚堆；指标统计并尽量避免。 |
| 设正 | `CorrectDesign` | 正确答案的来源与验证方式。 |
| 设误 | `MistakeRule` / `rule_defs` | 干扰项的构造规则 ID 与说明。 |
| 可接合性 | style/pos checks | 正确项与题干活用形、词性、句法位置可原样嵌入。 |

## 5. 失败与审计

| 术语 | 代码/路径 | 定义 |
|---|---|---|
| 缺陷码 | `E_PARSE` / `E_ANCHOR` / `E_ZERO` / `E_MULTI` | 结构失败码；前三者由 Item 校验产生，`E_MULTI` 由缺线索检查产生。 |
| 隔离 | `QualityStatus.QUARANTINED`；`data/exams/quarantine/` | 导入期隔离状态；迁移工具把无法迁移的旧题写到本目录。 |
| 审计 | `core.audit.audit_items` | 只读检查 Item/视图/请求日志；不调用 LLM/MDict。 |
| 漂移 | `DRIFT-NN` | 文档与代码的已知差异，统一登记在 L1-15。 |
| 迁移 | `tools/migrate_items_v1.py` | 把旧 `GeneratedQuestion` 转成 Item v1；失败写 quarantine。 |

## 6. 安全与配置

| 术语 | 代码/数据 | 定义 |
|---|---|---|
| provider | `LLM_PROVIDER` | `openai`（含 DeepSeek 兼容）或 `anthropic`。 |
| 显式 Key | `LLM_API_KEY` | 跨 provider 的显式覆盖；不设置时按 host 选择对应环境变量。 |
| 请求日志 | `core.request_log` | 只记录 prompt/元数据的本地 JSONL；不记录 Key、headers、response。 |
| 运行闭包 | runtime closure | 代码 + `vocab.json` + `grammar.json`；其余资源可选。 |
