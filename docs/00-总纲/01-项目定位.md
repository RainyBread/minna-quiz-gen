# 项目定位

## 1. 一句话

JLPTCraft 是面向大二上《综合日语3》的日语题库生成与教研 CLI：教材词表、语法点、锁表与原题库是事实源，LLM 只负责写载体句。

## 2. 用户与场景

- 教师/助教：按课次、题型、来源配比快速出一套练习或模拟卷。
- 学生：离线做读音/汉字题，或按主题做拓展练习。
- 维护者：用本地结构化数据与可执行命令复现、审计、迁移题库。

## 3. 交付底线

1. clone 仓库。
2. 只配置 LLM Key（可选；读音/汉字题不需要）。
3. 运行 `python init.py --check` 与 `python init.py`，即可出题。
4. 一键模拟卷：`python main.py --mock`（需要 LLM）。

运行数据随仓库提供；UniDic、MDict、教材 PDF、原题库、DB 都是可选本地增强，缺失时按契约降级。

## 4. 范围

- 学期：`big2_autumn`；教材绝对课次 37-50，课程课次 1-14。
- 可生成题型：`kanji_to_kana`、`kana_to_kanji`、`vocab_choice`、`expression_choice`、`grammar_fill`。
- 模拟卷：80 题五类，配比 30/10/5/10/25；不含阅读、排序、完形。
- 记录型题型：`translation_choice`、`sentence_ordering`、`cloze`、`reading` 只记录配比，本期不生成。

## 5. 非目标

- 不做 Web 前端、账号体系或在线题库服务。
- 不做 LLM-as-judge 或语义复核门禁；正确性来自本地答案、锁表与结构校验。
- 不把教材/真题/词典/API Key 提交到 Git。
- 不承诺“任意日语课程”通用；当前只覆盖大二上。
